# Phishing campaign case study: AiTM → BEC
Учебный разбор публичной кампании из [Microsoft, 2022-07-12](https://www.microsoft.com/en-us/security/blog/2022/07/12/from-cookie-theft-to-bec-attackers-use-aitm-phishing-sites-as-entry-point-to-further-financial-fraud/).
Это анализ опубликованного исследования, а не самостоятельно расследованный инцидент.
Нет живых фишинговых ссылок, реальных писем, cookies, образцов и данных жертв.

## Результат
- report/analysis.md — пример отчёта для аналитика и руководителя.
- data/sources.json и data/evidence.json — утверждения, источники и confidence.
- examples/evidence-register.md — воспроизводимый реестр доказательств.
- triage.py — небольшой исполняемый прототип поведенческой корреляции.
- examples/ — синтетические события и результат, не телеметрия кампании.

## Воспроизведение
Python 3.11+, без зависимостей. Из корня репозитория:
~~~sh
python3 report.py
python3 triage.py examples/synthetic-events.json
python3 -m unittest discover -s tests -v
~~~
Для обновления реестра: python3 report.py > examples/evidence-register.md.
Все проверки offline. Сеть используется только человеком при чтении источников.

## Метод
Сформулировать вопрос → выбрать первичный публичный отчёт → выписать утверждения
с разделами → отделить наблюдение автора от собственной интерпретации →
сопоставить ATT&CK → сформулировать проверяемые гипотезы детектирования.
Ссылки и даты доступа: data/sources.json, 2026-11-13.
ATT&CK — таксономия, не независимое подтверждение конкретной кампании.
Confidence medium: доступен отчёт компетентного первичного наблюдателя,
но нет собственной телеметрии и независимой проверки исходных артефактов.

## Ограничения
Отчёт исторический; текущая активность и принадлежность инфраструктуры не проверены.
IOC feed намеренно отсутствует: устаревшие адреса без контекста непригодны для блокировок.
Коррелятор демонстрирует идею, не production rule: необычность входа заранее задана
синтетическим событием, а не вычисляется по IP/географии. Нет заявленных метрик
precision/recall, факта компрометации или измеренного эффекта внедрения.
CI настроен; удалённый запуск ещё не подтверждён.
